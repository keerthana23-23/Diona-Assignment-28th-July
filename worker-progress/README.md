# Worker Progress Report

## Description

This project recreates the Worker Progress Report form using HTML, CSS, JavaScript, and Pug templates.

The form displays claim information and worker progress details using sample datasets. Different datasets can be selected from the dropdown to demonstrate how the page updates with different data.

## Files Included

- index.html
- styles.css
- script.js
- templates/mixins.pug
- templates/worker-progress.pug

## Features

- Multiple datasets
- Dataset switching
- Dynamic content rendering
- Automatic page numbering
- Worker App ID and submission date generation
- Printable PDF output
- Pug templates and mixins

## How to Run

1. Open index.html in a browser.
2. Select Dataset 1 or Dataset 2 from the dropdown.
3. Use Ctrl + P to view the printable PDF version.
